Engineering Principles

Native Performance
Built directly on platform primitives — Metal 3, ScreenCaptureKit, and CoreAudio on macOS; Next.js and Cloudflare edge workers on the web. Zero unnecessary bloat or battery drain.
Private by Default
Framebuffers, audio packets, and user sessions remain on-device in volatile RAM. No telemetry packages, no trackers, no user fingerprinting.
Open Source First
All applications are open source under MIT or permissive licenses. Inspect the code, fork it, audit it, or contribute back to the community.
