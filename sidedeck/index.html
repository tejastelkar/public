Engineering Architecture

Live macOS Hardware Integration
Interfaces directly with macOS IOKit.ps (Power Sources) to query live battery percentage, AC adapter status, and calculate battery depletion curves. Connects to CoreWLAN to read real wireless interface power, active network SSID, and RSSI dBm signal strength.
Spring Physics Callout Geometry
Every flyout popover features a mathematical callout beak shape computed in real time. The beak points precisely at the vertical center of the hovered card with zero pixel mismatch across density modes.
Key-Capable Floating Panel
Subclasses NSPanel with canBecomeKey = true and custom first-responder management. You can type tasks, edit checklist items, and take quick notes directly inside floating flyouts without bringing a heavy window forward.
Click-Through Transparency
Custom hitTest architecture passes mouse clicks through transparent bounds when idle, so underlying browser tabs, code editors, and desktop icons remain 100% interactive without phantom clicks.
Full Persistence & Zero Telemetry
All tasks, habit histories, water intake, notes, and customization preferences persist safely in local macOS UserDefaults. Zero network requests, zero telemetry, and zero tracking.
